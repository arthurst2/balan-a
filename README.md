# Usina de Concreto – Programação e Produção

Site de página única (sem servidor) para programar obras, controlar a produção do dia
e gerenciar a escala de motoristas e a frota de uma usina de concreto.

## Funções
- **Programação:** semana por dia, aviso de *cabe / apertado / cheio* e sugestão de horário livre.
- **Produção do dia:** grade no estilo planilha, horários automáticos, linha laranja para pendências e painel de caminhões.
- **Equipe e frota:** ordem de carregamento (arrastar), manutenção, rodízio e exportação da escala para Excel.

## Como usar
Abra o `index.html` no navegador, ou publique com o GitHub Pages
(Settings → Pages → Branch `main` → pasta `/ (root)`).

## Dados
Ficam salvos no navegador (localStorage) do computador em uso.
Use **Baixar backup** na aba *Equipe e frota* para guardar uma cópia.
